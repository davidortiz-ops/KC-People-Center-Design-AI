# Umbrales de calidad de contenido

## Conteo mínimo de palabras por tipo de página

| Tipo de página | Palabras mín. | % contenido único | Notas |
|-----------|-----------|-----------------|-------|
| Homepage | 500 | 100% | Debe comunicar claramente la propuesta de valor |
| Página de servicio / función | 800 | 100% | Explicación detallada de la oferta |
| Ubicación (principal) | 600 | 60%+ | Sede en la ciudad o área de servicio principal |
| Ubicación (secundaria) | 500 | 40%+ | Ubicaciones satélite |
| Post de blog | 1.500 | 100% | Contenido profundo y valioso |
| Página de producto | 400 | 80%+ | Descripciones únicas, especificaciones |
| Página de categoría | 400 | 100% | Intro único, no solo listados de productos |
| Página "Acerca de" | 400 | 100% | Historia de la empresa, equipo, valores |
| Landing page | 600 | 100% | Contenido enfocado en conversión |
| Página de FAQ | 800 | 100% | Preguntas y respuestas exhaustivas |

## Umbrales de páginas de ubicación

### Nivel de advertencia (30+ páginas)
- ⚠️ **ADVERTENCIA** a partir de 30+ páginas de ubicación
- Exigir 60%+ de contenido único por página
- El contenido debe incluir:
  - Información local única (puntos de referencia, barrios)
  - Servicios u ofertas específicos de la ubicación
  - Información del equipo o personal local
  - Testimonios genuinos de clientes de esa zona

### Parada obligatoria (50+ páginas)
- 🛑 **PARADA OBLIGATORIA** a partir de 50+ páginas de ubicación
- Requiere justificación explícita del usuario
- Debe demostrar:
  - Presencia comercial legítima en cada ubicación
  - Estrategia de contenido único para cada página
  - Señales locales (Google Business Profile, reseñas locales)

### Por qué importa
El algoritmo de doorway pages de Google penaliza las páginas de ubicación programáticas con contenido thin/duplicado. Señales de doorway pages:
- Solo cambia el nombre de la ciudad/estado entre páginas
- Sin información local única
- Sin señales de negocio local
- URLs con relleno de keywords

## Páginas programáticas seguras vs. riesgosas

### Seguras a escala ✅
| Tipo de página | Por qué es segura |
|-----------|---------------|
| Páginas de integración | Documentación de configuración real, contenido técnico único |
| Páginas de plantilla/herramienta | Recursos descargables, funcionalidad única |
| Páginas de glosario | Definiciones únicas de 200+ palabras |
| Páginas de producto | Especificaciones, imágenes y reseñas únicas |
| Páginas de perfil de usuario | Contenido único generado por usuarios |

### Riesgo de penalización ❌
| Tipo de página | Por qué es riesgosa |
|-----------|----------------|
| Páginas de ubicación con solo la ciudad cambiada | Contenido duplicado, doorway pages |
| "Mejor [herramienta] para [industria]" | A menudo thin, sin valor específico de la industria |
| "Alternativa a [competidor]" | Requiere datos de comparación genuinos |
| Contenido masivo generado por IA | Sin valor único, falla de E-E-A-T |

## Requisitos del title tag

| Aspecto | Requisito |
|--------|-------------|
| Longitud mínima | 30 caracteres |
| Longitud máxima | 60 caracteres (Google trunca ~60) |
| Keyword principal | Cerca del inicio |
| Nombre de marca | Al final (si se incluye) |
| Unicidad | Cada página debe tener un título único |

### Buenos ejemplos
- "Servicios de Plomería de Emergencia en Austin | ABC Plomería"
- "Cómo Reparar un Grifo que Gotea: Guía Paso a Paso"
- "Software SEO Empresarial | Plataforma Integral"

### Malos ejemplos
- "Inicio" (demasiado corto, no descriptivo)
- "Los Mejores Servicios de Plomería para Todas tus Necesidades de Plomería en Austin Texas y Áreas Cercanas" (demasiado largo)
- "ABC Plomería - Plomería - Plomero - Servicios de Plomería" (relleno de keywords)

## Requisitos de la meta description

| Aspecto | Requisito |
|--------|-------------|
| Longitud mínima | 120 caracteres |
| Longitud máxima | 160 caracteres (Google trunca ~155-160) |
| Llamado a la acción | Incluir un CTA convincente |
| Keyword principal | Incluir de forma natural |
| Unicidad | Cada página debe tener una descripción única |

---

## Requisitos del alt text de imágenes

| Aspecto | Requisito |
|--------|-------------|
| Requerido en | Todas las imágenes no decorativas |
| Longitud | 10-125 caracteres |
| Contenido | Describir el contenido de la imagen, no "imagen" ni el nombre de archivo |
| Keywords | Incluir de forma natural donde sea relevante |
| Imágenes decorativas | Usar `alt=""` o `role="presentation"` |

### Buenos ejemplos
- "Plomero profesional reparando el grifo del fregadero de cocina"
- "Sedán Toyota Camry 2024 rojo, vista frontal"
- "Reunión de equipo en sala de conferencias de oficina moderna"

### Malos ejemplos
- "image.jpg" (nombre de archivo, no descripción)
- "plomero plomería plomero servicios" (relleno de keywords)
- "Haz clic aquí" (no descriptivo)

## Pautas de enlazado interno

| Tipo de página | Objetivo de enlaces internos |
|-----------|----------------------|
| Post de blog (1.500+ palabras) | 5-10 enlaces internos |
| Página de servicio | 3-5 enlaces internos |
| Página de categoría | Enlaces a todas las páginas hijas |
| Página de producto | 2-4 enlaces internos |

### Reglas del anchor text
- Usa anchor text descriptivo (no "haz clic aquí")
- Varía el anchor text (no uses siempre keywords de coincidencia exacta)
- Enlaza a contenido relevante y relacionado
- Asegúrate de que no haya páginas huérfanas (cada página enlazada desde al menos otra)

## Señales de frescura del contenido

| Tipo de contenido | Frecuencia de actualización |
|--------------|------------------|
| Noticias/actualidad | En horas/días |
| Posts de blog (evergreen) | Revisar anualmente |
| Páginas de producto | Cuando cambien las especificaciones |
| Páginas de servicio | Revisar trimestralmente |
| Información de la empresa | Cuando ocurran cambios |

### Elementos requeridos
- Fecha de publicación visible (para artículos/blogs)
- Fecha de última actualización (si se revisó significativamente)
- Registro de cambios para actualizaciones mayores (opcional pero recomendable)
