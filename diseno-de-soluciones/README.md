# Diseño de Soluciones

> Chapter de **People Center Design - Pragma**.

Artefactos para la fase de **diseño de soluciones**, con foco en **experiencia de usuario,
accesibilidad y madurez de design systems**. Incluye evaluadores heurísticos, auditorías
de accesibilidad y material de referencia (proto-personas).

> Cada archivo es un prompt/skill autónomo en Markdown. Para ver y copiar su contenido
> cómodamente, abre `../index.html` (chapter **Diseño de Soluciones**).

## Notas

- **Auditor WCAG** y los evaluadores heurísticos (**Heuristy**, **Tognazzini**) son
  complementarios: el primero cubre accesibilidad (cumplimiento normativo) y los segundos
  usabilidad (principios de diseño).
- **Proto-Persona Banca Top Tier** es un insumo de referencia (no un agente): se usa como
  contexto de entrada para las evaluaciones y para validar decisiones de diseño.
- **Consultor de Madurez de Design Systems** opera a nivel organizacional, no de una
  interfaz puntual.
